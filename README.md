# Sarvadhara Tech Innovations - Ultra-Premium Website

An ultra-luxury, cinematic website for Sarvadhara Tech Innovations Private Limited featuring a black + platinum design system.

## 🎨 Design System

- **Background**: 100% Black
- **Primary Accent**: Platinum/Metallic Silver
- **Typography**: Playfair Display (luxury serif) + Inter (modern sans-serif)
- **Theme**: Ultra-premium, cinematic, enterprise-grade

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
npm start
```

## 📄 Pages

1. **Home** (`/`) - Company overview, hero section, two operating wings, founders
2. **Services** (`/services`) - Software services, portfolio, testimonials, service form
3. **Product** (`/product`) - SAAMRAS product showcase, solutions, video, achievements
